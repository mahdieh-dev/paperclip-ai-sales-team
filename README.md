# ساخت تیم فروش AI با Paperclip | ماهی‌دِو (MahiDev)

**یک مدیر AI و سه متخصص بساز که روی یک مسئله فروش با هم کار کنند، نه در چهار چت جدا.**

این مخزن آموزش فارسی ساخت یک تیم چهارایجنتی در [Paperclip](https://github.com/paperclipai/paperclip) است. برای تمرین، یک فروشگاه **کاملاً فرضی** و ۱۵ مکالمه ساختگی مشتری داریم. مدیر AI کار را به تحلیلگر، کارشناس فروش و کنترل کیفیت واگذار می‌کند و خروجی را برای بررسی به شما تحویل می‌دهد.

**این مخزن خودِ برنامه Paperclip نیست؛ راهنما، داده نمونه و دستورهای آماده راه‌اندازی تیم است.** هیچ اتصال آماده‌ای به دایرکت اینستاگرام یا پایگاه داده فروشگاه ندارد.

## از کجا شروع کنم؟

**اگر می‌خواهی خودت انجام بدهی:** [راهنمای قدم‌به‌قدم فارسی](docs/راهنمای-قدم-به-قدم.md) را از ابتدا دنبال کن. [نسخه PDF](docs/راهنمای-فارسی.pdf) هم موجود است.

**اگر می‌خواهی یک دستیار AI راهنمایی‌ات کند:** فایل [AI_SETUP_PROMPT.md](AI_SETUP_PROMPT.md) را باز کن و دستور داخل آن را همراه لینک این ریپو به دستیار بده. در چت معمولی ChatGPT، دستیار می‌تواند راهنمایی کند؛ اجرای واقعی نصب نیاز به دسترسی به کامپیوتر/ترمینال و تأیید کاربر دارد (مثلاً Codex CLI).

## مسیر سریع برای آشنایی (روی کامپیوتر)

- Node.js نسخه `24.11+` و دسترسی به Codex CLI لازم است؛ شرایط نصب به سیستم‌عامل و نوع اتصال بستگی دارد.
- نصب Paperclip بر اساس [راهنمای رسمی](https://github.com/paperclipai/paperclip/blob/master/docs/start/quickstart.md):

```bash
npx paperclipai@latest onboard --yes
```

- بعد از نمایش داشبورد Paperclip، مطابق [راهنمای کامل](docs/راهنمای-قدم-به-قدم.md) شرکت، CEO و سه متخصص را بساز.
- برای مأموریت اول، ابتدا فقط از فایل‌های `sample-data` استفاده کن و قبل از هر اقدام واقعی تأیید بده.

## محدودیت‌ها و ایمنی

- **هنوز تست کامل نصب چهار ایجنت در یک محیط زنده برای این بسته ثبت نشده است.** اگر نسخه Paperclip تغییر کرده باشد، صفحه‌ها و نام گزینه‌ها ممکن است متفاوت باشند؛ در این حالت مستندات رسمی مرجع است.
- قبل از استفاده از گفت‌وگوی واقعی مشتری‌ها، داده‌های شخصی را حذف و مجوز استفاده از داده‌ها را بررسی کن.
- هیچ پیام، ایمیل، دایرکت یا تغییر قیمت نباید بدون تأیید صاحب کسب‌وکار انجام شود.
- دستیار نباید مدعی شود نصب را انجام داده مگر واقعاً به محیط اجرا دسترسی داشته باشد و نتیجه را آزمایش کرده باشد.
